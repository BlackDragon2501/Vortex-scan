# Vórtex Scan

**Tus documentos, sin límites.** App de Vortex Company, parte de la suite Vórtex Studio.

Escáner de documentos y lector de códigos con la cámara del dispositivo o con archivos importados del almacén (móvil y PC).

- **Escaner**: captura con cámara o importa imágenes, gira páginas, marca las 4 esquinas del papel y el documento se aplanar (corrección de perspectiva por homografía), con filtros original / escala de grises / blanco y negro adaptativo / realce de contraste.
- **Exportación**: PDF multipágina (A4), PNG o JPG por página.
- **QR y códigos de barras**: detección en vivo con la webcam o desde una imagen; usa BarcodeDetector nativo (QR, EAN, UPC, Code 39/93/128, ITF, Codabar, PDF417, Aztec, DataMatrix) con respaldo jsQR para QR, con historial, copia y apertura de enlaces.

## Características

- Gratis, sin anuncios y sin cuentas de usuario.
- Todo el procesamiento ocurre en tu navegador: ninguna foto, grabación o texto se sube a ningún servidor.
- Funciona en PC y móvil (los permisos de cámara/micrófono se piden solo cuando los usas).
